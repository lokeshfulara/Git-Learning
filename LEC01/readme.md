1. git init      → New Git repository start karne ke liye
2. git status    → Current status dekhne ke liye
3. git add .     → Sab files stage karne ke liye
4. git commit -m "msg" → Changes save karne ke liye
5. git log       → Commit history dekhne ke liye
6. git branch    → Branches dekhne/banane ke liye
7. git switch branch-name → Branch change karne ke liye
8. git pull      → GitHub se latest code lane ke liye
9. git push      → Code GitHub par upload karne ke liye
10. git clone URL → Existing repository download karne ke liye

Flow: git init → git add . → git commit → git push
